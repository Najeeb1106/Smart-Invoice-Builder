# Contributing to Smart Invoice Builder

Thank you for considering contributing to **Smart Invoice Builder**! Contributions from the open-source community are what make this tool powerful, accessible, and privacy-first.

---

## 1. Code of Conduct

Please maintain a welcoming, inclusive, and professional environment. Respect all contributors and maintainers.

---

## 2. Development Setup

1. **Fork & Clone**:
   ```bash
   git clone https://github.com/Najeeb1106/Smart-Invoice-Builder.git
   cd Smart-Invoice-Builder
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Start Development Server**:
   ```bash
   npm run dev
   ```

4. **Run Unit Tests**:
   ```bash
   npx vitest run
   ```

5. **Verify Production Build**:
   ```bash
   npm run build
   ```

---

## 3. Pull Request Guidelines

- Branch naming convention: `feat/feature-name`, `fix/bug-description`, or `docs/update-readme`.
- Ensure all Vitest tests pass (`npx vitest run`).
- Ensure TypeScript compilation completes with 0 errors (`npm run build`).
- Use **Conventional Commits** format (`feat:`, `fix:`, `docs:`, `style:`, `refactor:`).
- Open a Pull Request against the `main` branch with a clear summary of your changes.

Thank you for helping make Smart Invoice Builder better!
