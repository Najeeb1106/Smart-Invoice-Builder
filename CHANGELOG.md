# Changelog

All notable changes to the **Smart Invoice Builder** project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [3.0.0] - 2026-08-13

### Added
- **12 Professional Invoice Templates**: Modern, Classic, Minimal, Bold, Corporate Blue, Creative Studio, Compact, Elegant, Tech/IT, Retail, Simple, and Startup themes.
- **5-Second Auto-Playing Animated Template Carousel**: Dynamic showcase carousel on the Landing Page featuring progress timer bars and hover-pause capability.
- **Fail-Proof Isolated Iframe Print Engine**: Native browser print workflow rendering clean A4 invoice documents without page blanking.
- **Sequential Section Unlocking**: Builder section step validation locking dependent steps until required fields are completed.
- **Location & Tax Details**: Extended business details supporting City, State/Province, ZIP/Postal Code, Country dropdown, Tax ID, and Website inputs.
- **Zero-Scroll Density Workspace**: Optimized editor forms, toolbar height, and live paper canvas scale for laptop screens (1366x768 / 1440x900).
- **WebP Image Compression**: Automatic client-side image compression for company logos.

### Security & Privacy
- Local-first architecture utilizing browser `localStorage` (0 backend database dependency).

---

## [2.0.0] - 2026-07-20

### Added
- Multi-currency support (USD, EUR, GBP, PKR, INR, CAD, AUD, JPY).
- Instant automatic financial calculation engine (Subtotal, Discount, Taxable Amount, Tax, Grand Total).

## [1.0.0] - 2026-06-01

### Added
- Initial release of Smart Invoice Builder with single-page form editor and basic A4 preview.
